# Data Dictionary and Transparency

The datasets in this project are synthetic, illustrative examples created to demonstrate an analytics workflow. They are not actual Mangiee account exports, verified competitor observations or researched partnership prospects.

- social_media_posts.csv: sample post-level metrics for six labels, ten posts per label.
- competitor_analysis.csv: anonymized competitor benchmark inputs.
- brand_lead_scoring.csv: illustrative prospect scores using branding needs, online presence and growth signals.

Replace all sample records with authorized or independently verified observations before drawing real business conclusions.
